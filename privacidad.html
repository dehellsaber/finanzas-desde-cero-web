Política de privacidad

Última actualización: 22 de noviembre de 2026.

Qué es esta aplicación

«Finanzas Canal» es una aplicación privada que utiliza únicamente el propietario del canal de YouTube «Finanzas desde Cero» para subir, programar y consultar sus propios vídeos mediante la API de YouTube. No está disponible para el público ni para otros usuarios.

Datos a los que accede

Solo accede, con autorización del propietario, a los datos de su propio canal de YouTube (vídeos, títulos, descripciones, miniaturas y estado de publicación). No recoge, almacena ni trata datos personales de terceros.

Uso y almacenamiento

Las credenciales de autorización se guardan de forma cifrada en el entorno privado del propietario y se usan solo para las acciones descritas. No se venden, comparten ni transfieren a terceros.

Servicios de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El propietario puede revocar el acceso en cualquier momento desde su cuenta de Google: myaccount.google.com/permissions.
